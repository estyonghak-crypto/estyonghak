# 무인도 생존기

혼자 하는 모바일 생존 게임입니다. 폭풍에 휩쓸려 무인도에 표류한 주인공으로, 나무와 돌을 모아 도구를 만들고, 사냥하고, 밤마다 찾아오는 늑대를 모닥불로 막으며 **5일째에 뗏목을 만들어 탈출**하는 것이 목표입니다.

설치나 빌드 없이 `index.html` 파일 하나로 동작합니다. 폰 브라우저에서도, PC에서도 열립니다.

## 플레이 방법

| 하고 싶은 일 | 터치 | 키보드 |
| --- | --- | --- |
| 이동 | 화면을 누른 채 드래그 | WASD / 방향키 |
| 행동 (베기, 캐기, 따기, 마시기, 공격, 굽기, 잠자기) | 오른쪽 큰 버튼 (꾹 누르면 반복) | 스페이스 / J |
| 먹기 | 위쪽 가방의 음식 터치 | E |
| 장비 교체 | 오른쪽 장비 슬롯 터치 ("자동" 칩으로 자동/수동 전환) | 1~5 (슬롯 선택), Q (다음 장비) |
| 건축 (울타리, 돌담, 문, 탑, 철거) | 건축 버튼 → 원 안을 터치하거나 드래그. 원 밖을 드래그하면 이동 | B (켜기/끄기), 1~5 / Q (종류 선택), 마우스 클릭·드래그 |
| 제작 | 제작 버튼 | C |
| 일시정지 | ☰ 버튼 | Esc |

행동 버튼의 글자는 가까이 있는 대상에 따라 바뀝니다.

## 생존 규칙

- **스탯**: 체력, 배고픔, 갈증, 체온. 배고픔, 갈증, 체온 중 하나라도 0이 되면 체력이 줄어듭니다.
- **낮과 밤**: 하루는 4분입니다. 밤에는 체온이 떨어지고 늑대가 나타납니다. 밤이 올수록 늑대가 늘어납니다.
- **모닥불**: 빛과 온기를 주고, 주변 원 안으로 늑대가 들어오지 못합니다. 장작을 넣어 계속 피울 수 있고 생고기를 구울 수 있습니다.
- **움막**: 낮은 안전지대입니다. 밤에 잠을 자면 아침으로 넘어가고 체력이 회복됩니다.
- **장비**: 도끼, 창, 곡괭이는 장착해야 효과가 납니다. 도끼는 나무를 2배로 얻고, 곡괭이는 돌을 3개씩 캐며, 창은 공격력 4에 사거리가 깁니다. 기본은 **자동 전환**이라서 나무 앞에선 도끼, 바위 앞에선 곡괭이, 동물이 가까워지면 창으로 알아서 바뀝니다. 슬롯을 직접 누르면 수동 모드가 되고, "수동" 칩을 누르면 다시 자동으로 돌아갑니다.
- **건축**: 건축 버튼을 켜면 캐릭터 주변에 원과 격자가 나타납니다. 원 안을 터치하면 한 칸, 드래그하면 선을 따라 울타리가 놓이고, 원 밖을 드래그하면 평소처럼 이동합니다. 행동 버튼은 캐릭터 앞 칸에 설치합니다.
  - **울타리**(나무 2, 체력 40), **돌담**(돌 4, 체력 140), **문**(나무 3, 돌 1, 체력 50). 문은 나만 지나갈 수 있고 동물은 못 지나갑니다.
  - **철거**: 재료의 절반을 돌려받습니다.
  - 벽이 길을 막으면 늑대와 화난 멧돼지가 벽을 물어뜯어 부숩니다. 부서지기 전에 벽 앞에서 행동 버튼(수리)으로 체력을 30씩 채우세요. 벽 너머 늑대는 창(사거리가 깁니다)으로 찌를 수 있습니다.
- **소총**: 제작 메뉴에서 만들고(나무 10, 돌 8) 장비 슬롯에서 장착합니다. 행동 버튼(발사)을 누르면 사거리 280 안에서 적대적인 동물(늑대, 화난 멧돼지)을 먼저, 없으면 가장 가까운 동물을 자동으로 조준해 쏩니다. 한 발에 6 피해로 늑대는 3발이면 쓰러지고, 탄환은 벽과 나무를 넘어갑니다. **탄약**은 제작 메뉴에서 돌 3 + 나무 1로 10발을 만듭니다. 자동 장비가 켜져 있으면 190 안에 적이 들어올 때 소총으로 바뀝니다.
- **탑**: 건축 팔레트의 "탑"(나무 10, 돌 6, 체력 90)은 사거리 240 안의 적대적인 동물을 혼자서 쏩니다(화살 4 피해, 1초에 한 발). 탄약은 처음에 10발이고 최대 30발이며, 탑 앞에서 행동 버튼(장전)을 누르면 가방의 탄약이 10발씩 채워집니다. 탄약이 떨어지면 머리 위에 빨간 느낌표가 뜹니다. 토끼와 얌전한 멧돼지는 쏘지 않습니다. 탑도 벽처럼 늑대가 물어뜯고, 수리하고, 철거하면 남은 탄약과 재료 절반을 돌려받습니다. 울타리 모서리에 세우면 좋습니다.
- **음식**: 열매(덤불, 다시 자랍니다), 토끼와 멧돼지 고기. 날고기는 몸에 해로우니 구워 먹으세요. 물은 호수에서 마십니다.
- **탈출**: 5일차부터 해안이나 호숫가에서 뗏목(나무 30, 돌 10, 구운 고기 3)을 만들면 승리합니다.

진행 상황은 브라우저에 자동 저장되고, 다음에 열면 "이어하기"로 이어서 할 수 있습니다.

## 폰에서 열어보기

- **GitHub Pages**: 저장소 Settings → Pages에서 이 브랜치의 루트(`/`)를 배포하면 `https://<사용자>.github.io/<저장소>/` 주소로 열립니다.
- **같은 와이파이의 PC에서**: 이 폴더에서 `npx http-server -p 8080`을 실행하고, 폰 브라우저에서 `http://<PC의 IP>:8080`을 엽니다.
- 브라우저 메뉴의 "홈 화면에 추가"를 쓰면 앱처럼 전체 화면으로 실행됩니다.

## 밸런스 조정

`index.html` 위쪽 스크립트의 상수를 바꾸면 됩니다.

- `DAY_LEN`: 하루 길이(초)
- `RAFT_DAY`: 뗏목을 만들 수 있는 날
- `FIRE_SAFE`, `FIRE_WARM`: 모닥불의 안전 반경과 온기 반경
- `RECIPES`: 제작 목록과 재료
- `TOOLS`: 장비별 채집량, 공격력, 사거리, 휘두르는 속도
- `WALLS`: 울타리, 돌담, 문, 탑의 체력과 재료 (`GRID`, `BUILD_RANGE`는 격자 크기와 건축 반경)
- `GUN_RANGE`, `GUN_DMG`, `AUTO_GUN_RANGE`: 소총 사거리, 피해량, 자동 장비 전환 거리 / `TOWER_RANGE`, `TOWER_DMG`, `TOWER_AMMO_MAX`: 탑 사거리, 피해량, 탄약 한도
- `updateCreatures()`의 `damageWall(...)`: 늑대와 멧돼지가 벽에 주는 피해량
- `SPECS`: 토끼, 멧돼지, 늑대의 체력, 속도, 피해량
- `update()` 안의 `P.hunger`, `P.thirst`, `P.warmth` 감소 속도

## 개발 메모

- 외부 라이브러리 없이 Canvas 2D와 순수 JavaScript로 만들었습니다. 폰트만 Google Fonts에서 불러오며, 실패하면 기본 한글 폰트로 대체됩니다.
- 헤드리스 Chromium(모바일 뷰포트 390×844, 360×640, 가로 844×390, 데스크톱 1280×720)에서 이동, 채집, 제작, 장비 교체, 건축, 늑대의 벽 공격과 수리, 소총 자동 조준과 탑의 자동 사격, 탄약 장전, 요리, 늑대 방어, 전투, 수면, 저장/이어하기, 승리/패배 흐름을 확인했습니다. 실제 기기에서의 터치 감각과 성능은 아직 확인하지 못했습니다.
